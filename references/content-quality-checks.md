# Content quality checks

Run these before delivering. They come from real review feedback on drafts that read fine but weren't ready to ship.

1. **Who we are.** Is there a section showing the people behind the business (founder note, point of view, manifesto)? For a new business with no portfolio this is the biggest trust gap. If names, background or beliefs are missing, ask.
2. **Specific differentiators.** For each "why us" point, can a visitor name a concrete thing behind it (what the strategy document contains, what is in the launch kit, what exactly is fixed in scope)? If a competitor could paste the same line, rewrite it with a true detail or placeholder it.
3. **No assumed situation.** Does any line presume something about the visitor that may not be true (a finished product, an existing brand, a budget)? Reword to cover the whole audience.
4. **Soft claims sourced.** Statements such as "first impressions decide trust" or "rebrands cost more later" need a source or a safer wording. Use a softer true phrasing when no source exists. Log each in the Claim Ledger.
5. **Headline clarity.** Do headline + subheadline together say what you do, for whom, and the outcome? Offer one alternate that names the visitor's pain directly for A/B testing.
6. **Ambiguity sweep.** Read each line as a stranger. Any phrase with two meanings gets replaced with the plain version.
7. **Metaphors and name stories.** If a name rationale or metaphor needs a sentence to explain it, shorten it or cut it.
8. **Audience coverage.** If the audience includes relaunches or people with a rough brand to fix, does some copy speak to them directly?
9. **Placeholders can't ship.** Every bracketed item has an empty-state plan: hide the section, "coming soon" state, or fallback copy. Work and testimonial sections are the usual offenders.
